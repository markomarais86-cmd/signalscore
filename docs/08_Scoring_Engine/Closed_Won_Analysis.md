# Closed-Won Analysis

## Overview

Closed-won analysis identifies patterns in historical wins to calibrate ICP criteria and feature weights.

## Data Requirements

**Minimum**: 50 closed-won deals  
**Recommended**: 100+ deals  
**Optimal**: 500+ deals

**Required Fields**:
- Company name/domain
- Close date
- Deal value
- Employee count
- Industry
- Geography

## Analysis Process

1. **Data Upload**: Import closed-won deals (CSV or CRM sync)
2. **Pattern Detection**: Statistical analysis of common attributes
3. **Weight Calculation**: Derive feature weights from correlations
4. **ICP Recommendations**: Suggest optimal ICP criteria

## Output Insights

- Top industries (by win rate)
- Optimal company size range
- Geographic concentration
- Technology stack patterns
- Revenue sweet spot
- Funding stage correlation

## Using Results

- Update ICP criteria
- Apply calculated weights
- Validate against current accounts
- Re-score all accounts
